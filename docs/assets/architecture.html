Agent Eval Harness — Architecture

Does the agent actually complete the task? Grades the whole trajectory — every tool call, steps vs optimal, and cost — not just the final answer.

Run

  • • manual tool-use loop over 12 multi-step tasks
  • • deterministic tool world: calculator · search · lookups
  • • records every step, tool call and token

Score

  • • success rate (numeric-tolerant / substring)
  • • tool-call accuracy: precision/recall/F1 vs the reference trace
  • • step efficiency (optimal/actual, capped at 1.0) + cost per task

It separates agents

  • • heuristic (competent): 1.00 success · 1.00 tool-F1
  • • naive (deliberately flawed): 0.58 success · 0.59 tool-F1
  • • a good eval separates agents, it doesn't rubber-stamp them
